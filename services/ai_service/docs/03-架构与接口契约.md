# 架构与接口契约（T5）

> 项目：小语手记·RAG 智能问答
> 本文件是 T11-T18 的实现依据，先写契约再写代码。

---

## 1. 目标架构

```text
浏览器（手机/电脑）
   │  博客阅读 + AI 问答页（ai_chat.html + ai_chat.js）
   │  HTTP + SSE（唯一入口）
   ▼
Flask 主站 :5000（网关）
   │  校验登录态、注入 X-User-Id、注入 X-Internal-Token、透传 SSE
   ▼
FastAPI AI 服务 :8100（RAG 核心）
   ├── 检索链路：召回 → 重排 → 阈值
   ├── 生成链路：Prompt → LLM 流式
   ├── 会话历史 / 检索感知缓存
   └── 可观测性：日志 / 指标
   ▼
依赖服务
   ├── Ollama :11434（Embedding，本地 GPU）
   ├── 硅基流动 API（Rerank，云端）
   ├── 通义 / DeepSeek API（LLM，云端）
   ├── Qdrant 192.168.56.200:6333（向量库）
   ├── Redis 192.168.56.200:6379（历史 / 缓存）
   └── MySQL 127.0.0.1:3307（语料来源，只读同步）
```

**核心原则**：
- 浏览器只认 `Flask :5000`，AI 服务不直接对外；
- 登录态只在 Flask 判定，AI 服务只信内部 Token；
- Dify 只在验证期使用，生产链路不依赖。

## 3. 核心接口契约

### 3.1 POST /api/ai/chat/stream

浏览器唯一见到的路径，由 Flask 网关提供。

**请求体**：

```json
{
  "question": "string, 1..500 字符",
  "session_id": "string, 8..64 字符"
}
```

**网关注入头（浏览器不填）**：

| Header | 值 | 作用 |
|---|---|---|
| `X-Internal-Token` | 与 AI 服务共享的密钥 | 网关 → AI 鉴权 |
| `X-User-Id` | Flask session 中的用户 ID | 可信身份，用于日志与限流 |

**成功响应**：`Content-Type: text/event-stream`

事件序列：

```text
event: sources    → {"items":[{"title","article_id","score"}, ...]}
event: delta      → {"text":"..."}          （重复 N 次）
event: done       → {"elapsed_ms":1820}
data: [DONE]
```

**拒答响应**：

```text
event: refused    → {"text":"这个问题在我的笔记里没有找到相关内容……"}
event: done       → {"elapsed_ms":120}
data: [DONE]
```

拒答不调用 LLM，直接返回固定话术。

**错误响应**：

```text
event: error      → {"code":"...", "message":"服务暂时不可用，请重试"}
data: [DONE]
```

**HTTP 状态码**：

| 状态码 | 场景 |
|---|---|
| 200 | 正常流式返回 |
| 401 | 未登录（Flask 判定）或内部 Token 错误（AI 判定） |
| 422 | 参数非法（question 为空/超长，session_id 格式错） |
| 429 | 超过限流阈值 |
| 500 | 内部错误 |
| 502 | AI 服务不可用（网关无法连接上游） |

### 3.2 事件协议详解

| 事件 | data 结构 | 时机 | 前端动作 |
|---|---|---|---|
| `sources` | `{"items":[{"title","article_id","score"}]}` | 检索完成后立即发 | 渲染“参考文章”卡片 |
| `delta` | `{"text":"..."}` | 逐 token | 追加到答案区 |
| `refused` | `{"text":"..."}` | 拒答分支 | 展示话术，结束 |
| `done` | `{"elapsed_ms":1820}` | 生成结束 | 停 loading，写历史 |
| `error` | `{"code":"...","message":"..."}` | 任意环节异常 | 友好错误 + 重试 |
| `ping` | `{}` | 每 15s 代理保活 | 忽略 |

### 3.3 内部接口（网关 → AI）

```text
POST http://127.0.0.1:8100/api/ai/chat/stream
```

请求体与对外一致，额外要求携带：

```text
X-Internal-Token: <共享密钥>
X-User-Id: <用户 ID>
```

AI 服务校验 Token，失败返回 401。

### 3.4 调试接口（仅开发期）

| 路径 | 作用 | 鉴权 |
|---|---|---|
| `GET /health` | 依赖健康状态 | 无 |
| `GET /metrics` | 聚合指标（只暴露聚合值） | 无 |
| `GET /api/ai/debug/retrieve?q=...` | 检索质量肉眼调试 | 开发期无，生产期下线 |

## 4. 降级矩阵

| 依赖 | 挂了的表现 | 策略 | 类型 |
|---|---|---|---|
| Redis | 无历史 / 无缓存 | fail-open：照常问答，日志 warn | 可降级 |
| Rerank API | 退化为向量分排序 | fail-open：答案质量降、功能在 | 可降级 |
| MySQL（同步用） | 语料暂时不更新 | fail-open：旧语料继续服务 | 可降级 |
| Qdrant | 主链路断裂 | 不可降级：明确 error 事件 | 不可降级 |
| Embedding | 主链路断裂 | 不可降级 | 不可降级 |
| LLM 主模型 | 生成失败 | 自动切 DeepSeek 备选 | 可降级（切备选） |
| LLM 全挂 | 无法生成 | 不可降级：error 事件 | 不可降级 |

**降级原则**：牺牲体验保可用，主链路牺牲了就什么都不剩。

## 5. 限流与超时

| 项目 | 规则 |
|---|---|
| 限流 | 网关按 `user_id` 每分钟 10 次，超额返回 429 |
| LLM 超时 | 60s |
| Embedding 超时 | 10s |
| Rerank 超时 | 10s |
| 客户端断开 | 服务端检测 `request.is_disconnected()`，取消生成 |
| 代理保活 | 每 15s 发 `ping` 事件 |

## 6. 信任边界

```text
浏览器 ──▶ Flask :5000 ──▶ FastAPI :8100 ──▶ 依赖服务
          │                │
          │                └── 只信 X-Internal-Token + X-User-Id
          └── 登录态唯一判定点
```

- Flask 是唯一鉴权入口，判定 `session.get("is_login") == "true"`；
- AI 服务不校验登录态，只校验内部 Token；
- 若 `:8100` 直接暴露，任何人都能伪造身份，因此**必须绑 127.0.0.1**；
- `X-User-Id` 由 Flask 从 session 取，浏览器无法伪造。

## 8. 一句话总结

**浏览器 → Flask :5000（网关：登录态 + 代理 SSE）→ FastAPI :8100（RAG 链路）→ Qdrant / Redis / 模型服务**；对外只有一个入口，内部 Token 划清信任边界，SSE 事件协议 `sources → delta* → done → [DONE]`，依赖按可降级 / 不可降级分级处理。
