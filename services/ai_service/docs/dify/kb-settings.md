## 分段设置
- 分段方式：通用分段
- 分段标识：`\n\n`
- 最大长度：800
- 重叠长度：50
- 文本预处理：移除多余空格、移除 URL 和邮箱
- 元数据头：保留（标题 / 分类 / 标签 / 日期）

> 说明：手册建议 500/50 是通用起点；本项目文章平均 500 字符，500 上限会频繁触发切分，因此调整为 **800/50**，让“一篇 = 一个 chunk”成为默认结果。

- 地址：`http://host.docker.internal:11434`
- 索引状态：88 篇全部 `completed`

- Rerank：开启
- Rerank 模型：`BAAI/bge-reranker-v2-m3`（硅基流动）
- Top K：5
- Score 阈值：0.4（初始值，待 T10 实验 B 校准）

## 与手册的差异说明
1. 手册假设 Dify 在 Windows 本地运行，实际 Dify 在 Windows Docker 中运行，因此 Ollama 地址使用 `host.docker.internal:11434`。
2. 手册建议分段 500/50，实际调整为 800/50（文章平均 500 字符）。
3. 手册初始阈值 0.4，实测无效，待 T10 实验 B 校准。
4. Dify 社区版不支持 `.jsonl` 直接上传，已改用逐篇 TXT + API 批量导入。
